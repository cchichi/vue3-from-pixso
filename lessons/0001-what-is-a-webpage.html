今天这一步很小，但它决定后面所有课的底子——你 Pixso 里的每一页设计稿，本质上就是一堆排列好的「盒子」。先学会看盒子，后面才能把盒子变成代码。

网页是「三件套」，本课只学第一件

一个网页 = 三种语言各司其职（先混个脸熟，本课只用第一种）：

语言管什么类比
HTML结构：页面上有哪些东西、谁套着谁房子的骨架与房间布局
CSS长相：颜色、大小、间距、圆角装修与家具摆放
JavaScript行为：点了按钮会怎样、数据从哪来水电与「活人」

来源：MDN：Web 开发入门（中文）

为什么零基础也从 HTML 开始？ 因为 Vue3 页面里写结构的那部分（叫 template）就是 HTML 加了一点魔法。HTML 是通往 Vue 的第一级台阶，没有捷径。

核心思想：标签 = 带名字的盒子

HTML 的全部秘密只有一句话：

网页的内容，都装在一个个「带名字的盒子」里；盒子一层层套着盒子。

这种「盒子」在 HTML 里叫标签（英文 tag / element）。大多数标签要成对出现：

<!-- 开标签：告诉浏览器“一个盒子从这里开始，它叫 div” -->
<div>

<!-- 盒子里的内容写中间 … -->

<!-- 闭标签：比开标签多一个斜杠 /，告诉浏览器“盒子到这里结束” -->
</div>

常见的几种「盒子」：

标签它是什么盒子
<div>最通用的盒子，装啥都行（页面布局的主力）
<h1> … <h6>标题盒子（h1 最大，往下越来越小）
<p>一段文字的盒子
<ul> + <li>列表盒子（ul 是整列，li 是每一行）
<img>、<button>图片盒子、按钮盒子（这类不用写闭标签的少数派，先记住名字即可）

完整速查表见 HTML 速查表（第 1 课参考）。

两条铁律

① 开标签和闭标签必须配对，<div>…</div>。
② 盒子只能一层套一层，不能交叉：先开的后闭，像剥洋葱一样从外往里关。

一个网页文件的最小骨架

任何网页（包括以后 Vue 生成的）最外面都是这个壳：

<!-- 声明：我是 HTML5 文档 -->
<!doctype html>
<html lang="zh-CN">      <!-- 最外层大盒子：整个页面 -->
  <head>                 <!-- 大脑盒子：页面的设置信息，浏览器看、人不看 -->
    <meta charset="UTF-8" />   <!-- 让中文不乱码 -->
    <title>页面标题</title>     <!-- 浏览器标签页上显示的字 -->
  </head>
  <body>                 <!-- 身体盒子：页面上真正显示的东西都在这 -->
    <h1>你好，世界</h1>
    <p>这是我的第一个网页。</p>
  </body>
</html>

请盯着看 30 秒：html 套着 head 和 body；body 里再套内容——还是盒子套盒子。

来源：MDN：构建网页内容（中文）

练习 1（纸面练习，5 分钟）：去你的 Pixso 稿里找盒子树
  1. 打开 Pixso，挑一个最简单的页面（比如一张信息卡 / 一个设置项）。
  2. 看左侧图层面板：里面一层层缩进的图层名，就是设计稿的「盒子树」——顶层是整页，展开后是区块、再里面是文字和图片。
  3. 把最外面三层结构抄下来，例如： 
    页面
└─ 卡片（最外层盒子）
   ├─ 标题「我的订单」
   └─ 列表
      ├─ 订单 1
      └─ 订单 2

不用追求完美，抄三层就行。抄完把结果发给老师（我）看一眼——这一步在训练你「用盒子的眼睛看设计稿」，是第 7 课转化的核心能力。

练习 2（动手，15–20 分钟）：写出并打开你的第一个页面
  1. 模板已经给你建好了：vue3-coach/practice/index.html（在课程文件夹里）。
  2. 在 VS Code 里打开它：菜单「文件 → 打开文件夹」选 vue3-coach/practice，然后点左侧文件名 index.html。
  3. 先读一遍，找到三样东西：最外层是哪个标签？标题是哪个标签？列表用哪两个标签？
  4. 动手改（改完保存 ⌘S）：把「小明」改成你的名字；把爱好列表加一行；再在卡片里新增一个 <div> 盒子，里面随便写一句话。
  5. 双击 index.html（或在 VS Code 里点右下角「Go Live」之前，先用最简单的方式：在访达里双击它）——浏览器会打开它。
  6. 在浏览器里刷新（⌘R），确认你改的字都变了，虚线框住的地方就是一个个盒子。
  • 我的页面能在浏览器里打开
  • 我改了名字并刷新后看到了变化
  • 我新增了一个 <div> 并看到新的虚线框
  • 我能指着页面说出「这个区域是哪个标签」

1. 网页的「骨架 / 结构」由哪种语言负责？

2. 哪个写法是「开标签」？

3. 关于盒子嵌套的说法，正确的是？

这节课你赢了什么

  • 一句话复述 HTML：网页内容装在带名字的盒子里，盒子一层套一层。
  • 会认最常见的标签：html / head / body / h1 / p / div / ul / li。
  • 写出了你的第一个网页文件，并会改、会刷新、会看结果。
  • 开始用「盒子眼」看你的 Pixso 设计稿。
