第 2 课：给盒子上妆 —— CSS 与盒模型

预计 30–40 分钟 · 前提：已完成第 1 课的两个练习 · 第 2 课

回顾 10 秒

第 1 课我们建立了世界观：网页 = 带名字的盒子（HTML 标签）一层套一层。HTML 回答「有什么」，CSS 回答「长什么样」——就像 Pixso 里同一块内容，可以描边、填色、调间距。

本课结束你会：给任何 HTML 盒子加上颜色、圆角、内外边距，并能说清楚「盒模型」的四层结构——这是第 7 课把 Pixso 样式翻译成代码的必备技能。

CSS 的一句话语法

CSS 的每一条规则都是：选谁（选择器）→ 设什么（属性: 值;）

/* 给页面上所有的 h1 上妆： */
h1 {
  color: #2c7a5f;      /* 文字颜色 */
  font-size: 28px;     /* 字号：px 是像素 */
}

读法：「选中的 h1，文字颜色设为深绿，字号设为 28 像素」。每行结尾有分号 ;，别漏。

写在哪里？最简单的做法：写在 HTML 文件的 <head> 里的 <style>…</style> 中（你第 1 课的 practice/index.html 里已经有了一个，只是我们当时只用来描边）。

两种选择器，本课够用

选择器写法选中谁HTML 里的配合
标签选择器h1 { … }所有同名标签无需改动
类选择器.card { … }所有带这个 class 的元素<div class="card">

「类」就像给人贴标签：同一页可以有多个 class="card" 的盒子，一条 CSS 就给它们全部上妆。贴标签用 HTML，定妆用 CSS，职责分明。

盒模型：一个盒子的四层结构

每个 HTML 盒子，从外到里都是四层（这是 CSS 最重要的一个模型，必须背下来）：

┌─ margin（外边距：盒子与其他盒子之间的距离）─────┐
│ ┌─ border（边框：盒子的墙，可描边/圆角）───────────┐ │
│ │ ┌─ padding（内边距：内容与边框的距离）─────┐ │ │
│ │ │  content（内容：文字 / 图片 / 子盒子）      │ │ │
│ │ └───────────────────────────────────────────┘ │ │
│ └───────────────────────────────────────────────┘ │
└───────────────────────────────────────────────────┘

口诀：「从外到里：margin → border → padding → content」。Pixso 里你调间距时——元素之间的空白大致对应 margin，元素内部的留白对应 padding，描边对应 border。能对号入座，后面翻译样式就顺了。

马上感受一下（10 秒实验） 打开你的 practice/index.html，找到 section 的样式，把 padding: 12px 改成 60px 保存刷新——看到没？内容离虚线框变远了，这就是 padding（内边距）。改完改回来，再试试 margin。

本课常用属性速查

属性作用示例
color文字颜色color: #333;
background背景颜色background: #fff;
font-size字号font-size: 20px;
border-radius圆角（越大越圆）border-radius: 12px;
padding内边距（内容↔边框）padding: 16px;
margin外边距（盒子↔盒子）margin: 8px auto;
text-align文字对齐text-align: center;
width盒子宽度width: 320px;

颜色除了 #2c7a5f 这种十六进制，也可以直接写单词 red、white。想挑颜色：Pixso 里每个图层的属性面板就有色值，直接抄过来用！

练习（动手 15–20 分钟）：把你的名片卡真正「装修」起来

打开 vue3-coach/practice/index.html（若你第 1 课改过，就用你自己的版本），按顺序做：

  1. 给 body 加浅灰背景，例如 background: #f0f0f0;
  2. 让 section（你的卡片）变成「真卡片」：白底 background: #fff;、圆角 border-radius: 12px;、去掉原来的虚线描边（删掉 border: … 那行）、加内边距 padding: 20px;、左右居中 margin: 40px auto; + 一个宽度 width: 340px;
  3. 给 h1 换颜色与字号（试着用 Vue 绿 #42b883）
  4. 把「我的爱好」那块 div 加个类 class="box"，然后用类选择器 .box { … } 给它浅绿底 background: #e6f5ee; 和圆角 border-radius: 8px;
  5. 体验差异：分别把 padding 与 margin 调大再调小，刷新观察——哪个影响「框内」，哪个影响「框外」？
  • 我的卡片是白底圆角、页面是浅灰底（像 Pixso 里的卡片效果了）
  • 我能用类选择器 .box 只给一块区域上妆
  • 我能说清 padding 和 margin 各自管「框内」还是「框外」
  • 我把每一步都保存（⌘S）并刷新（⌘R）看到了变化
样式没生效？按顺序查这三样 ① <style> 是否在 <head> 里且拼写正确；② 属性行是否以分号 ; 结尾；③ 类名拼写是否一致——HTML 里 class="box"，CSS 里必须写 .box（有点号、拼写完全一样）。
