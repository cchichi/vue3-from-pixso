第 3 课：让页面会动手 —— JavaScript 基础

预计 40–50 分钟 · 前提：已完成第 1、2 课练习 · 第 3 课

回顾 10 秒

HTML 定了「有什么」，CSS 定了「长什么样」，但到今天为止，你的页面是静止的——像一张导出的 PNG。JavaScript 是第三件套：它让页面动起来、会响应——点按钮换内容、数据变化页面跟着变。

Vue3 本质上是在帮你更省力地写 JS；所以这一步的底子打牢，第 4 课你会觉得 Vue 特别顺手。

本课结束你会：在名片卡上加一个按钮，点击后页面上的文字真的会变。这也是「假数据联通」里「按钮→变内容」交互的最小雏形。

把代码放进哪里：<script>

JS 写在 <script>…</script> 里，惯例放在 <body> 的最后一行之前（保证页面元素都先画出来，脚本再去找它们）：

</body>          <!-- 这之前是页面的 HTML -->
<script>
  // 你的 JS 写在这里；// 是单行注释
</script>
</body>

JS 注释用 //（CSS 用 /* */，别混）。

变量：给数据起个名字

网页里到处是数据：用户名、价格、订单状态。把数据存进变量，之后就能反复用它：

const name = "小明";      // 常量：存进去就不能改（推荐默认用它）
let count = 0;            // 变量：以后还要改它的值（比如计数）

console.log(name);        // 在浏览器开发者工具里打印出来给你看
  • const（不能改）与 let（能改）——以后写代码 99% 用这两个；老教程里的 var 别学。
  • 字符串要加引号："小明"；数字不用：0。
  • console.log(…) ：在页面按 ⌥⌘I 打开开发者工具 → Console 面板，能看到打印结果——这是你的「调试小窗口」。

函数：给一组动作起个名字

函数 = 打包好的一组动作，起个名字，随时调用：

function sayHello() {
  console.log("你好，页面活了！");
}

sayHello();   // 调用：执行函数里打包的动作（注意后面的括号）

读法：「定义一个叫 sayHello 的函数，它做的事是打印一句话；然后调用它一次」。定义时不执行，调用（写名字 + 括号）时才执行——这个区别后面常考。

让按钮干活的公式（本课核心）

让「点按钮 → 页面变化」发生，只需要三步公式：

// 1. 找到按钮（选择器语法和 CSS 一样！）
const btn = document.querySelector("button");

// 2. 定义要执行的动作（函数）
function changeName() {
  document.querySelector("h1").textContent = "你好，我是新名字！";
}

// 3. 告诉按钮：点击时执行这个动作
btn.addEventListener("click", changeName);

逐句翻译：

  • document.querySelector("button") = 「在页面里找第一个 button，给我」——括号里写 CSS 选择器，跟第 2 课学的 .box、h1 完全同一套语法。
  • .textContent = "…" = 「把这个元素的文字换成…」
  • addEventListener("click", changeName) = 「监听点击事件，点了就调用 changeName」
理解小窍门 第 1 课盒子 + 第 2 课上妆 + 本课「找到盒子、改它内容」——等你学 Vue 时，会发现 Vue 把「找到盒子」和「改内容」都包办了（用 ref 和模板），你只需要管数据。但先亲手做一遍，你才知道 Vue 替你省了多少事。
练习（动手 20–25 分钟）：让名片卡上的按钮真正干活

打开你的 practice/index.html（第 2 课装修过的版本），做下面四步——其中有几处是 ____ 空，自己填：

  1. 在卡片的 <h1> 下面加一个按钮： 
    <button>点我换名字</button>
  2. 在 </body> 前加上 <script>…</script>，把下面代码抄进去，并填好三处空： 
    <script>
  // 1. 找到按钮
  const btn = ____.querySelector("button");

  // 2. 动作：把 h1 的文字换成你自己的名字
  function changeName() {
    document.querySelector("____").textContent = "你好，我是____！";
  }

  // 3. 点击时执行
  btn.addEventListener("____", changeName);
</script>
  3. 保存 ⌘S → 浏览器刷新 ⌘R → 点按钮。h1 变了 = 你成功了。
  4. （进阶挑战）再做一个「计数器」：页面显示 <p>点了 0 次</p>，每次点按钮数字 +1。提示：需要一个 let count = 0，在函数里 count = count + 1，再把 count 填回那个 <p> 的文字里。
  • 我的按钮在页面上显示出来了
  • 点按钮后 h1 的文字真的变了
  • 我能说出三个空分别为什么填 document、h1（或类名）、click
  • （可选）计数器每次点击 +1
点了没反应？按顺序查： ① <script> 是否在 </body> 前；② 三个空是否填对（document / h1 / click）；③ 按钮和 h1 的名字有没有拼错；④ 打开开发者工具 Console（⌥⌘I）看有没有红色报错，把报错文字发给我。

1. 想存一个「以后还要改」的数，用哪个关键字？

2. 定义函数后，什么时候才真正执行？

3. 让按钮「点击后执行某个函数」，用哪句？

这节课你赢了什么

  • 会用 const / let 存数据，会用 console.log 看结果
  • 会定义并调用函数：function fn() {…} → fn()
  • 背下了「按钮干活三连」：querySelector 找 → 函数定动作 → addEventListener("click", fn) 挂上
  • 你做出了人生第一个「点一下会变」的网页
