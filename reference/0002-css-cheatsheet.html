CSS 速查表

配合第 2 课使用 · 可打印，随时回查

一句话世界观

CSS 负责「长相」：选谁（选择器）→ 设什么（属性: 值;）。HTML 定结构，CSS 定样式，两者分离。

规则语法（直接复制）

/* 标签选择器：选中所有 h1 */
h1 {
  color: #2c7a5f;    /* 文字颜色 */
  font-size: 28px;   /* 字号 */
}

/* 类选择器：选中所有 class="card" 的元素 */
.card {
  background: #fff;
  border-radius: 12px;
  padding: 20px;
  margin: 40px auto;   /* 上下 40px，左右自动居中 */
  width: 340px;
}
  • HTML 里贴标签：<div class="card">…</div>
  • CSS 里选标签：.card { … }（点号 + 完全相同的类名）
  • 属性行以分号 ; 结尾，注释用 /* … */

盒模型（必须背）

margin  →  盒子与其他盒子的距离（框外）
border  →  边框 / 墙（描边、圆角）
padding →  内容与边框的距离（框内留白）
content →  内容本体（文字 / 图片 / 子盒子）

从外到里：margin → border → padding → content。

对号入座（Pixso ↔ CSS）：元素间空白 ≈ margin；元素内留白 ≈ padding；描边 ≈ border。

常用属性速查

属性作用示例
color文字颜色color: #333;
background背景色background: #e6f5ee;
font-size字号font-size: 20px;
border-radius圆角border-radius: 12px;
padding内边距（框内）padding: 16px;
margin外边距（框外）margin: 20px auto;
width宽度width: 340px;
text-align文字对齐text-align: center;
border描边（粗细 样式 颜色）border: 2px solid #ccc;
font-weight字重（粗体）font-weight: 700;

颜色格式：#2c7a5f（十六进制）或单词 red。Pixso 属性面板里的色值可直接抄。

常见坑 & 排错顺序

  1. <style> 要在 <head> 里，拼写正确
  2. 属性行结尾的分号 ; 别漏
  3. 类名一致：HTML class="box" ↔ CSS .box
  4. 改完要保存 ⌘S + 刷新 ⌘R；还没效果就右键页面 →「检查」，看 Elements 面板里样式有没有被划掉
