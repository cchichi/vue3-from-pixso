JavaScript 速查表

配合第 3 课使用 · 可打印，随时回查

一句话世界观

JavaScript 管「行为」：数据存在变量里，动作打包进函数，事件（如点击）触发函数去改页面。

写法与注释

// JS 写在 <script>…</script> 里，放在 </body> 之前
// 单行注释用 //，多行用 /* … */

变量与输出（直接复制）

const name = "小明";   // 常量：不可改，默认用它
let count = 0;          // 变量：要改的值用 let

console.log(name);      // 开发者工具 Console 里查看（⌥⌘I）
  • 字符串加引号 "…"，数字不加引号
  • 不用 var（旧写法）

函数（直接复制）

function sayHello() {
  console.log("你好");
}

sayHello();   // 调用才执行：名字 + 括号

定义 ≠ 执行；调用（写名字 + 括号）才执行。

「按钮干活三连」（本课核心）

// 1. 找到元素（括号里是 CSS 选择器）
const btn = document.querySelector("button");

// 2. 定义动作
function changeName() {
  document.querySelector("h1").textContent = "你好，我是新名字！";
}

// 3. 绑定点击事件
btn.addEventListener("click", changeName);
工具作用
document.querySelector("选择器")在页面里找到第一个匹配的元素（选择器语法同 CSS）
元素.textContent = "…"改元素的文字内容
元素.addEventListener("click", fn)点击时执行函数 fn

常见坑 & 排错顺序

  1. <script> 放 </body> 之前
  2. 变量先声明再用；名字拼写一致（大小写敏感：count ≠ Count）
  3. 每行结尾：语句一般以 ; 收尾（漏了通常也能跑，但养成习惯）
  4. 没反应就开开发者工具 Console（⌥⌘I）看红字报错
